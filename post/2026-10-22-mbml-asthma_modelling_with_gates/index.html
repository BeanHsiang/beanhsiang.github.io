[译]基于模型的机器学习 - 6.4 用门建模

2026年10月22日
 | Model-Based Machine Learning
 | 阅读

门允许因子图的一部分被打开或关闭。

在上一节中，我们看到了如何通过手工推断一个“在多个可选过程之间做选择”的随机变量上的后验分布，来比较这些可选过程。现在我们将看到如何通过定义一个合适的模型、并在该模型内执行推断来完成同样的计算。为此，我们需要一种新的建模结构，它允许在模型中表示各种可选项。我们可以用来做这件事的建模结构称为门（gate），如 Minka and Winn [2009] 所述。

门把因子图的一部分包围起来，并根据一个称为选择变量（selector variable）的随机变量的状态来打开或关闭这部分。当选择变量取某个特定值（称为键，key）时，门是打开的；对所有其他取值，门是关闭的。图 6.11 的因子图中展示了一个门的例子。门以一个虚线矩形表示，键值（true）位于左上角。选择变量 selector 有一条边连接到门——边上的箭头表明门被视为选择变量的子节点。当 selector 等于 true 时，门是打开的，于是 x 服从 Bernoulli(0.2) 分布。否则门是关闭的，x 服从均匀分布，因为此时它没有连接到任何因子。

图 6.11：一个包含门（以虚线矩形表示）的因子图示例。当 selector 等于键值 true（显示在门的左上角）时，门是打开的，变量 x 服从 Bernoulli(0.2) 分布。当 selector 为 false 时，门是关闭的，x 服从均匀分布，因为它没有连接到任何因子。

在为带门的因子图写联合分布时，所有与门内那部分图相关的项，都需要根据选择变量是否取键值而被打开或关闭。这类项可以通过取零次幂来关闭，通过取一次幂来保持打开。例如，图 6.11 的联合分布为：

$$P(\text{selector}, \text{x}) \propto \text{Bernoulli}(x;0.2)^{\delta(\text{selector}=\text{true})} \tag{6.12}$$

其中函数 $\delta()$ 在括号中的表达式为真时等于 1，否则等于 0。如果 selector 不为 true，那么 $\text{Bernoulli}(x;0.2)$ 这一项将被取零次幂，使该项等于 1——这相当于把它从乘积中移除（即把它关闭）。

在模型中使用门时，常见的做法是为选择变量的每个取值各设一个门。在这种情况下，由此得到的一组门称为门块（gate block）。因为选择变量只能取一个值，所以一个门块中一次只能有一个门是打开的。图 6.12 的因子图中展示了一个门块的例子。在这个例子中，选择变量是二值的，因此门块中有两个门，一个键值为 true，另一个键值为 false。选择变量也可以有任意多个取值，从而得到包含相应数量的门的门块。

图 6.12：一个包含门块的因子图示例。当 selector 等于 true 时，左门打开、右门关闭，因此 x 服从 Bernoulli(0.2) 分布。当 selector 等于 false 时，左门关闭、右门打开，因此 x 服从 Bernoulli(0.9) 分布。

这个因子图的联合概率分布为：

$$P(\text{selector}, \text{x}) \propto \text{Bernoulli}(x;0.2)^{\delta(\text{selector}=\text{true})} \; \text{Bernoulli}(x;0.9)^{\delta(\text{selector}=\text{false})}. \tag{6.13}$$

观察这个联合概率，你也许能发现：selector 和 x 之间的门块表示一个条件概率表，如下所示：

表 6.4：图 6.12 中的门块所表示的条件概率表。

再举一个例子，我们可以用门这样来表示皮肤测试（图 6.1）的条件概率表：

图 6.13：用门块表示的皮肤测试（图 6.1）条件概率表。如果 sensitised 为 true，则左门打开、右门关闭。皮肤测试结果 skinTest 此时服从 Bernoulli 分布，取 true 的概率由 probSkinIfSens 给出。如果 sensitised 为 false，则 skinTest 服从 Bernoulli 分布，取 true 的概率由 probSkinIfNotSens 给出。

用门块来表示这个条件概率表，比用一个 Table 因子（如我们在图 6.1 中所做）要不那么紧凑，但其优点是让父变量与子变量之间的关系更加清晰和精确。当一个变量有多个父节点时，用门块来表示条件概率表还能带来更准确或更高效的推断。

用门做模型选择

表示条件概率表只是用门所能实现之事的开端。例如，门还可以用来做模型选择。为了说明如何做到这一点，让我们回到上一节的模型选择问题。记得我们希望通过推断一个叫做 model 的随机变量的后验分布，来在“有效”模型和“无效”模型之间做选择。使用门，我们可以把这个模型选择问题表示为一个单一的大型因子图，其中使用一个以 model 为选择变量的门块。然后我们把整个“无效”模型放进一个键值为 NoEffect 的门里，把整个“有效”模型放进该门块中另一个键值为 HasEffect 的门里。观测变量留在两个门之外，因为它们对两个模型都是公共的，因此始终是打开的。其结果就是图 6.14 中的因子图。

图 6.14：一个使用门在两个模型之间做模型选择的因子图。“有效”模型在上方的门中，“无效”模型在下方的门中。观测数据变量位于两个门之外，因为它们对两个模型都是公共的。当选择变量 model 取值 HasEffect 时，上门打开、下门关闭，因此“有效”模型生效。当 model 取值 NoEffect 时，上门关闭、下门打开，因此“无效”模型生效。因为 model 是一个取值未知的随机变量，推断它的后验分布就等价于在两个模型之间做贝叶斯模型选择。

这个因子图看起来也许有点吓人，但它可以被拆分理解。上方的门恰好包含图 6.10 中的模型，观测变量在门外。下方的门恰好包含图 6.9 中的模型，只是上下颠倒地画出，并共享相同的观测变量。最后我们有一个新变量，也就是用来做模型选择的 model 变量。

给定这个因子图，我们只需运行期望传播来推断 model 上的后验分布。对吧？嗯，差不多——事实证明，我们首先需要对期望传播做一些扩展，才能处理门。好消息是，这些修改使得期望传播可以应用于任何包含门的因子图。

带门因子图中的期望传播

推断深入探究

在这个可选的小节中，我们将看到如何用期望传播来计算模型证据，然后如何扩展期望传播以在含门的图上工作。如果你想聚焦于建模，可以放心跳过本节。

要在包含门的因子图中运行期望传播，我们首先需要能够为一个不含门的因子图计算模型证据。事实证明，我们可以用现有的 EP 消息，单独为每个变量和因子计算证据贡献，然后把它们相乘，从而得到模型证据的一个近似。例如，变量 x 的证据贡献由下式给出：

$$\text{evidence}_x = \sum_x (\text{进入 } x \text{ 的所有消息之积}) \tag{6.14}$$

这个方程表示：要计算变量 x 的证据，先取连接到该变量的各边上所有传入消息之积，然后对 x 可能取的各个值求和（这正是记号 $\sum_x$ 的含义）。由于有这个求和，其结果是一个单一的数而不是一个分布——这个数就是对模型证据的局部贡献。

连接到多个变量 $Y$ 的因子 f 的证据贡献由下式给出：

$$\text{evidence}_f = \frac{\sum_Y f(Y) \times (\text{进入因子 } f \text{ 的所有消息之积})}{\sum_Y (\text{进入或离开因子 } f \text{ 的所有消息之积})} \tag{6.15}$$

在这个方程中，记号 $\sum_Y$ 表示对相连变量 $Y$ 的所有联合配置求和。

我们可以用方程 (6.14) 和 (6.15) 来计算因子图中每个变量和每个因子的证据贡献。所有这些贡献之积给出模型证据的 EP 近似。对于一个模型 $M$，这给出：

$$\text{evidence}_M = \prod_{x \text{ 在 } M \text{ 中}} \text{evidence}_x \times \prod_{f \text{ 在 } M \text{ 中}} \text{evidence}_f \tag{6.16}$$

在方程 (6.16) 中，第一项表示模型 $M$ 中每个变量的证据贡献之积，第二项表示模型 $M$ 中每个因子的证据贡献之积。

加入门

如果我们现在转向包含门的因子图，就会出现一种新的证据贡献，它来自任何穿越门边界的边。如果这样一条边连接一个变量 x 和一个因子 f，那么其证据贡献为：

$$\text{evidence}_{fx} = \sum_x (\text{从 } x \text{ 到 } f \text{ 的消息}) \times (\text{从 } f \text{ 到 } x \text{ 的消息}) \tag{6.17}$$

换句话说，我们取在这条边上双向传递的两个消息之积，然后对变量 x 的各个取值求和。

在因子图的局部部分上计算证据贡献的好处在于：除了能为整个模型计算证据外，我们还能为任何特定的门计算证据。一个门的证据，是门内所有变量和因子的证据贡献、连同任何穿越门边界的边的贡献之积。对于一个门 g，这个积由下式给出：

$$\text{evidence}_g = \prod_{x \text{ 在 } g \text{ 中}} \text{evidence}_x \times \prod_{f \text{ 在 } g \text{ 中}} \text{evidence}_f \times \prod_{fx \text{ 穿越 } g} \text{evidence}_{fx} \tag{6.18}$$

如果没有边穿越门边界——换句话说，门包含一个与图其余部分断开的完整模型——那么这个方程就退化为上面的模型证据方程 (6.16)，从而给出所含模型的证据。

有了这些证据贡献，我们现在可以定义一个扩展版本的期望传播，它适用于包含门的因子图。该算法要求门只出现在门块中，并且要求：任何连接到门块某个门中某因子的变量，也要连接到该门块所有其他门中的因子。这种“门平衡”可以通过在任何该变量尚未连接因子的门中，把它连接到均匀因子来实现。我们需要这种门平衡，是因为消息将被定义为往返于门块，而不是往返于单个门。

当从一个门 g 内的因子 f 向门外的一个变量 x 发送消息时，我们需要对该消息适当加权，权重定义为：

$$\text{weight}_{gfx} = \frac{\text{evidence}_g}{\text{evidence}_{fx}} \times (\text{来自选择变量的消息})[\text{key}] \tag{6.19}$$

其中记号 $[\text{key}]$ 表示：我们在选择变量传来的消息所给出的分布下，评估该门的键值的概率。利用这些权重，我们可以定义扩展的期望传播算法，如算法 6.1 所示。

算法 6.1　带门的期望传播

输入： 带门块的因子图、要计算边缘分布的目标变量列表、消息传递调度、初始消息值（可选）、每条边的近似分布类型选择。

输出： 目标变量的边缘分布。

  1. 把所有消息初始化为均匀分布（若提供了初始值则用初始值）。
  2. 对消息传递调度中的每条边，按下面的规则发送相应消息：
    • 选择变量 → 门块： 选择变量其他各连接边上收到的所有消息之积；
    • 门块 → 选择变量： 选择变量上的一个分布，其中每个取值的概率与“键值为该值的门”的证据成正比；
    • 门块中的因子 → 门块外的变量： 用 (6.19) 给出的权重，计算各门中因子消息的加权和。再乘以上下文消息（即从该变量发往门块的消息）。用矩匹配投影到所需的分布类型。最后除掉上下文消息。
    • 所有其他消息： 常规 EP 消息（定义于算法 3.1）。
  3. 直到所有消息收敛为止。
  4. 在每个目标变量节点处，把所有传入消息相乘，计算其边缘分布。

该算法的完整推导见 Minka and Winn [2009]，其中还包含一些我们在此省略的额外细节（例如如何处理嵌套的门）。

现在我们有了一个适用于带门图的通用推断算法，就可以用它来同时做贝叶斯模型选择、并推断我们所关心变量上的后验分布了！例如，回想第 6.3 节中的示例试验。在那个试验中，治疗组 20 人中有 13 人康复，而对照组 20 人中有 8 人康复。把这些数据附加到图 6.14 的带门因子图上，我们可以应用期望传播来计算 model 选择变量以及 probTreated、probControl 等其他变量上的后验。结果展示在图 6.15 中。

图 6.15：每组 20 人的示例试验的推断后验分布。左图展示 HasEffect 模型中 probControl 和 probTreated 的后验。右图展示 model 变量上的后验分布。

图 6.15 显示，model 上的后验分布给“有效”模型的概率略高于“无效”模型。确切的取值是 model = HasEffect 为 0.5555，model = NoEffect 为 0.4445。这两个概率的比值就是贝叶斯因子，此处为 1.25。这与我们在第 6.3 节中手工计算的值相同，表明对于这个模型，期望传播的后验是精确的。probControl 和 probTreated 上的后验分布说明了为什么贝叶斯因子这么小。图中显示两个分布有大量重叠，这意味着两个概率有可能是同一个值，换句话说，“无效”模型可能成立。

让我们看看当我们增大试验规模、但保持每组中康复者比例不变时会发生什么。对于一个三倍规模的试验，这将是治疗组 60 人中有 39 人康复，而对照组 60 人中有 24 人康复。把这些新数据代入我们的模型，得到图 6.16 所示的结果。

图 6.16：每组 60 人的示例试验的推断后验分布。左图展示 HasEffect 模型中 probControl 和 probTreated 的后验。右图展示 model 变量上的后验分布。

图 6.16 显示，在把试验规模扩大三倍后，“有效”模型有了高得多的概率 0.904，给出 9.41 的贝叶斯因子。由于这个因子落在 3–20 的区间内，这次试验的结果现在可以被视为支持“有效”模型的正面证据。probControl 和 probTreated 上的后验分布说明了为什么贝叶斯因子现在大了很多：两条曲线的重叠少了很多，意味着两个概率相同的可能性大大降低了。我们可以更进一步，再次增大试验规模，使之达到原始试验的五倍。在这个更大的试验中，治疗组 100 人中有 65 人康复，而对照组 100 人中有 40 人康复，给出图 6.17 所示的结果。

图 6.17：每组 100 人的示例试验的推断后验分布。左图展示 HasEffect 模型中 probControl 和 probTreated 的后验。右图展示 model 变量上的后验分布。

在图 6.17 中，probControl 和 probTreated 上的后验分布几乎完全不重叠。因此，“有效”模型现在的概率为 0.989，给出 92.4 的贝叶斯因子。由于这个因子落在 20–150 的区间内，这次试验的结果现在可以被视为支持“有效”模型的强证据。这些结果表明：如果你想证明新药的有效性，运行一个足够大的临床试验是多么重要！

既然我们理解了如何用门在随机对照试验模型中建模可选项，我们就准备好用门来在过敏模型中建模可选的致敏类别了，我们将在下一节看到这一点。

本页引入的概念回顾

门（gate） 因子图中的一个容器，它允许所包含的那部分图根据图中另一个随机变量（称为选择变量）的取值被打开或关闭。门可以用来在模型中创建可选项，也可以用来做模型选择。关于门的更多细节见 Minka and Winn [2009]，或其扩展版本 Minka and Winn [2008]。

选择变量（selector variable） 一个控制门打开或关闭的随机变量。门会指定一个特定的键值——当选择变量取该值时门是打开的，取任何其他值时门是关闭的。选择变量的一个例子见图 6.11。

门块（gate block） 一组门，每个门有一个不同的键值，对应选择变量的各个可能取值。对于选择变量的任何取值，门块中会有一个门打开、其他所有门关闭。图 6.12 的因子图中展示了一个门块的例子。
