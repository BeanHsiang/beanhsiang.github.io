[译]基于模型的机器学习 - 6.5 发现致敏类别

2026年10月27日
 | Model-Based Machine Learning

既然我们的建模工具箱里有了门，我们就可以扩展过敏模型，让不同的孩子能够拥有不同的过敏获得与丢失模式。你也许还记得，在第 6.2 节中，我们想要做的模型改动是编码这个修改后的假设：

5 与特定过敏原初始致敏、获得致敏或保持致敏相关的概率，对每个致敏类别中的所有孩子都是相同的。

这个假设要求每个孩子都属于某个致敏类别，但我们并不知道每个孩子属于哪个类别。我们可以用一个针对每个孩子的 sensClass 随机变量来表示这种未知的类别归属，它取值为 $0, 1, 2, \dots$，取决于孩子在类别 0、类别 1，等等。因为这个变量可以取多于两个的值，我们不能用 Bernoulli 分布来表示它的不确定取值。相反，我们需要一个离散分布（discrete distribution），它是 Bernoulli 分布向“取多于两个值的变量”的推广。

[译]基于模型的机器学习 - 6.4 用门建模

2026年10月22日
 | Model-Based Machine Learning

门允许因子图的一部分被打开或关闭。

在上一节中，我们看到了如何通过手工推断一个“在多个可选过程之间做选择”的随机变量上的后验分布，来比较这些可选过程。现在我们将看到如何通过定义一个合适的模型、并在该模型内执行推断来完成同样的计算。为此，我们需要一种新的建模结构，它允许在模型中表示各种可选项。我们可以用来做这件事的建模结构称为门（gate），如 Minka and Winn [2009] 所述。

门把因子图的一部分包围起来，并根据一个称为选择变量（selector variable）的随机变量的状态来打开或关闭这部分。当选择变量取某个特定值（称为键，key）时，门是打开的；对所有其他取值，门是关闭的。图 6.11 的因子图中展示了一个门的例子。门以一个虚线矩形表示，键值（true）位于左上角。选择变量 selector 有一条边连接到门——边上的箭头表明门被视为选择变量的子节点。当 selector 等于 true 时，门是打开的，于是 x 服从 Bernoulli(0.2) 分布。否则门是关闭的，x 服从均匀分布，因为此时它没有连接到任何因子。

[译]基于模型的机器学习 - 6.3 比较可选模型

2026年10月17日
 | Model-Based Machine Learning

在前面所有章节中，我们都假设数据源自单一的潜在过程。但现在我们不能再这样假定了，因为我们预期：会发展出过敏和哮喘的孩子与不会发展出的孩子，遵循的是不同的过程。为了处理这类可选过程，我们需要引入一种新的建模技术。

这种技术将使我们能够：

  • 在单个模型中表示多个可选过程；
  • 评估每个可选过程产生某个特定数据项（例如某个特定孩子的数据）的概率；
  • 比较两个或更多不同的模型，看看哪一个最能解释某些数据。

为了介绍这项新技术，我们暂时把哮喘项目放在一边，转而看一个双过程情形的简单例子（如果你更愿意继续聚焦于哮喘项目，可以直接跳到第 6.5 节）。既然我们身处医学领域，有一个绝佳的双过程情形可用：随机对照试验。随机对照试验是一种临床试验，常用于检验各类医疗干预（如新药）的有效性。在这类试验中，每个受试者被随机分配到治疗组（接受实验性干预）或对照组（不接受干预）。试验的目的是判断实验性干预是否对一个或多个关注的结局有影响，并理解这种影响的性质。
